# Credit Card Fraud Detection using Machine Learning

A machine learning-based fraud detection system developed using Python and Scikit-learn to identify fraudulent credit card transactions from highly imbalanced datasets.

---

## Features
- Data preprocessing and cleaning
- Handling imbalanced datasets
- Feature engineering
- Fraud classification using machine learning
- Model evaluation using ROC-AUC, precision, recall, and F1-score

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## Machine Learning Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Model Training
5. Fraud Classification
6. Model Evaluation

---

## Algorithms Used
- Logistic Regression
- Random Forest Classifier

---

## Evaluation Metrics
- Precision
- Recall
- F1-Score
- ROC-AUC

---

## Dataset
Credit Card Fraud Detection Dataset used for training and testing.
